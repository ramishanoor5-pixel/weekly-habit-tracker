# Weekly Habit Tracker

## About the Project

The Weekly Habit Tracker is a simple and interactive web application built using HTML, CSS, and JavaScript. It helps users organize their daily habits and track their progress throughout the week.

This project is part of my JavaScript Intermediate internship Task 4, where I am practicing DOM manipulation, event handling, and event delegation.

## Features

* **Add Habits:** Create new habits, such as drinking water or reading for 20 minutes.
* **Track Daily Progress:** Mark habits as completed for each day of the week.
* **Rename Habits:** Edit existing habit names.
* **Delete Habits:** Remove habits that are no longer needed.
* **Interactive Grid:** View habits and their completion status in a weekly grid.
* **Event Delegation:** Handle grid interactions efficiently using event delegation.

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JavaScript)
